# Решения MVP

## Принято

- нативное Android-приложение;
- первое устройство Samsung Galaxy S21 Ultra;
- проводной ADB как provisioning/diagnostic channel;
- конечный пользовательски проверяемый список мест;
- круговые геозоны и лимит 100;
- детерминированный локальный JSON;
- Google Play services Geofencing API;
- локальные уведомления;
- read-only UI правил, журнала и диагностики;
- постоянный SQLite/WAL-журнал без автоматического удаления;
- JSONL-экспорт;
- boot re-registration;
- GitHub Actions debug APK;
- отдельный физический и battery experiment.

## Уточнение 7 сентября 2026: latency и заметность

По пользовательскому наблюдению «напоминание обнаружилось уже после прихода в
место» зафиксированы **две отдельные продуктовые характеристики**, которые нельзя
смешивать:

- задержка доставки geofence event до приложения;
- заметность уже опубликованного уведомления для человека.

Принято направление: геонапоминание должно иметь узнаваемое звуковое поведение,
чтобы отличаться от общего потока push-уведомлений. Конкретный паттерн пока не
выбран: короткий звук, ограниченный повтор или короткая мелодия остаются
вариантами для аппаратной проверки.

`responsiveness_ms` не является обещанием времени срабатывания. Для снижения
latency сохраняется low-power geofencing architecture; continuous GPS,
foreground location service и polling ради «мгновенного» уведомления не
добавляются без отдельного решения.

Если для выбранного звука понадобится менять default auditory behavior, нужно
создавать новый versioned Android notification channel: уже созданный channel не
считать программно перенастраиваемым после создания. Пользователь сохраняет
контроль над звуком/каналом, DND и системное отключение не обходятся.

Бесконечное воспроизведение, alarm-style foreground playback и самопроизвольное
повышение громкости не входят в принятое поведение MVP.

Полный контракт и критерии проверки:
[`PRODUCT_FEEDBACK_2026-09-07.md`](PRODUCT_FEEDBACK_2026-09-07.md).

## Отложено

- сервер и MCP control plane;
- push-синхронизация;
- production signing и Google Play publication;
- удалённое редактирование;
- PWA;
- POI/category expansion;
- полигоны;
- Huawei/HMS;
- multi-user accounts.

## Отклонено для MVP

- постоянно работающий агент на телефоне;
- foreground location service;
- частый polling;
- continuous GPS;
- server-side movement history;
- автоматическое обнаружение «любых супермаркетов»;
- единое недоказуемое состояние «уведомление показано».
